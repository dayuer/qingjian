这个项目的 iOS 版已经开发了一轮，实现和设计稿有不少出入。请把设计稿改成**和现在的实现一致**：已有的屏照下面改，没有的屏新画，作废的屏标「作废」（灰掉、保留原图，不删）。

**通用规则（每屏都适用）**

- 屏号沿用现有编号；新画的屏放进对应文件，屏号接着第 3 轮编：`3a`、`3b`……，标签里写「第 3 轮 · 已实现」。改过的旧屏在标签后加「（已按实现更新）」。
- 只画 iOS。Android 那几屏（01 的 1g/1h、02 的 1e、03 的 1d、04 的 1e、05 的 2k）不动。
- 配色：**键盘里**灰绿只给「代表某个人」的元素（牌子、提示行、头像、关于某人的提醒、「记到某人」按钮、首选候选字）；**App 里**照原稿用灰绿（开关、进度条、「+ 记一条」、日历选中日、「好了」）。新画的「待整理」原话一节、出错横幅一律中性色，不用灰绿。
- 字体：App 所有文字（含原来的衬线大标题）改用 MiSans，字重不变；**键盘**对象卡的名字与头像字保留宋体衬线，其余用系统字体。
- 「场景」整个概念已删除：凡是写着恋爱 / 日常 / 工作、场景名、选场景的地方都去掉。
- App 里不出现「账号」「登录」「注册」。
- 颜色 token 不变（`--accent` #C0E7C6、`--accent-ink` #2E4A34、`--accent-soft` #E8F9EB、`--ink-3` #747474）。新加两条线色：提示行下沿 `oklch(0.91 0.035 150)`（#D2E8D5），牌子竖线 `oklch(0.88 0.04 150)`。

## 01 键盘

**整块键盘的几何（改所有键盘屏）：** 照 iOS 26 自带键盘。

- 尺寸：工具栏 / 候选栏高 **50**（原 46）；键高 **44.5**（原 42）；圆角 **8.5**（原 5）；键间距 **6.3**；行间距 **11.5**；左右边距 4。
- 键面：白底，下方 1pt 黑 18% 阴影，按下时上方冒出 36pt 字母气泡。
- 键位：照 iOS 简体拼音。
  - 第三行：⇧ z x c v b n m ⌫。
  - 底行：「123」、😀、空格（右下角一个 11pt 灰色小「拼」）、return 键（用回车图标，不写「发送」）。
  - 去掉「分词」「英」。
- 拼音不另起 `.k-py` 一行：写在宿主输入框里，带下划线的 marked text。
- 候选格：
  - 高 40、圆角 8，字号 22，左右各留 10pt，最窄 40。
  - **首选候选带一块灰底**（黑 7%），选了人时首选字用 `--accent-ink`、500 字重。
  - 右端是 48 宽的 ⌄，前面一根 26 高的竖线。点开后候选铺满键区，流式换行，可上下滚。
- 提示行：高 34，`--accent-soft` 底，下沿 1pt 提示行线色。从左到右：6pt 灰绿点、12.5pt 灰绿字（命中词加粗）、右侧 28pt 圆形向上箭头。

**1a 打字时的记忆提示**：按上面的几何重画，内容不变。

**1b 键盘里看对象卡**：
- 头部：56pt 宋体头像、18pt 宋体名字（名字显示**代号**，没有代号才用真名）、「认识 n 天」。
- 卡片：最多 3 条，白底圆角 14。左列 44 宽、宋体 13：有日子写「今天 / 明天 / 周X / M.dd」（灰绿），没日子写种类「喜好 / 近况…」（ink-3）。右边是正文和关键词小字（「 · 」连接）。
- 页脚：左边「只显示与今天有关的 n 条」，右边「全部记忆」（灰绿）。点了页脚换成 2 秒的「打开素笺 App → 记住的」：键盘不能跳 App，只给文字路径。
- 工具栏只剩牌子和右端一个向下箭头（收起对象卡）。去掉「今早学习过」。

**1c 空闲工具栏 → 改成新屏「3a 工具栏：左边切人、右边切技能」**，画四个状态：
1. **默认**。从左到右：
   - 牌子：30 高胶囊，`--accent-soft` 底，7pt 灰绿点 + 13pt 灰绿人名；没选人写「不指定」。
   - 「记一笔」。
   - 技能按钮：文字就是当前技能名，例如「润色」。
   - 最右：28pt 向下箭头（收起键盘）。
   - 文字按钮都是 13pt ink-2。
   - **牌子不再拆成两半。**
2. **点了牌子**：牌子留在左边，右边横排最多 6 个其他人的白底胶囊（13pt，置顶的人在前，再按最近使用排），最后一个「不指定」。点一个就换人并收起。
3. **点了技能按钮**：整条换成一排技能胶囊，第一个「用默认」，后面是「润色」「高情商」等。当前选中的 ink 字 + 1.5pt 灰绿描边，其余 ink-2 字。点一个立刻用它改写。
4. **今日提醒**：提示行写「明天是她的生日」，右侧「知道了」（11.5pt ink-3）代替箭头。

**新屏「3b 改写结果条」**（占工具栏那一条），三态并排画：
- **改写中**：小转圈 +「改写中…」。
- **出结果**：
  - 左边技能名（12pt ink-2），中间改写后的句子（17pt ink，一行，太长截掉开头）；**点句子就替换原文**，没有单独的确认按钮。
  - 后面接那排技能胶囊（点别的技能就换它重改）。
  - 最右 ✕（放弃改写）。
- **失败**：灰字「改写没成功，检查网络后再试」或「没改好，换一个试试」，其余同上。
- 旁注：改写范围是选中的文字，没选中就是光标所在的这一句（往回到上一个句号 / 问号 / 叹号 / 分号 / 换行）。

**新屏「3c 没开完全访问」**：
- 牌子换成一行 12.5pt ink-2 文字「改写和记忆都要开完全访问。开了也不会上传你没让它上传的内容。」，没有圆点、没有底色。「记一笔」和技能按钮都不显示。
- 点它展开成整条说明：两行「开启完全访问后才能用记忆。开了也不联网，卡片只在这台手机上」+ 右侧线框胶囊「去开启」。点「去开启」后文字换成路径「设置 → 通用 → 键盘 → 键盘 → 素笺 → 允许完全访问」（键盘不能跳设置）。
- 两种状态都画。

**1d 场景与对象选择**：标「作废」。没有场景了，换人在工具栏里（3a）。
**1f 工作场景**：标「作废」。

**1e 记一笔：复制对方的话**：
- 确认条高 49，取代提示行。
  - 左边两行：「刚复制的」（多段时「刚复制的 · 3 条」，11pt ink-3）+ 原文一行（13pt ink-2）。
  - 右边：「忽略」（ink-2）+「记到阿美」灰绿实底胶囊（「记到」后面紧跟代号，不加空格）。

- 加画一个存好后的 toast：34 高，灰底，灰绿小点 +「记下了 2 条，明早整理」（没开云服务写「，开通素笺云后整理」）。
- 加画一个失败 toast：灰点 +「这个人还有 200 条没整理，先去 App 里看看」。
- **新屏「3d 手写一笔」**：没复制东西时点「记一笔」，提示行变成输入条。
  - 输入条：`--accent-soft` 底，占位字「记一件关于阿美的事」，右边「取消」+「记到阿美」灰绿胶囊（空着时 40% 透明）。
  - 工具栏只剩牌子。

**1e-2 草稿卡**：
- 键盘总高不变：**提示行收起**，高度让给草稿卡。
- 顶上一行「原话」（11pt ink-3）+ 原文一行 +「展开」。
- 字段卡：白底圆角 10，每行左边 12pt ink-3 标签（计划 / 时间 / 地点），中间可编辑文字，右边 ✕。
