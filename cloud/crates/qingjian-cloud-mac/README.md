# 青简 Cloud 的 Mac 端

链在输入法进程里，**不另起常驻程序**：状态与操作在输入法「中☁ → 青简 Cloud ›」子菜单里。
网络与读写同步文件都在后台线程，主线程每 0.5 秒只做几件微秒级的检查（剪贴板变更计数、取已收到的事件），不卡输入；
通用剪贴板从别的设备送来的条目主线程不读（读会跨设备取数据）。**崩了自己重启**：后台线程 panic 后 5 秒起按退避重跑
（学习数据从磁盘重读状态），主线程这边出错 10 秒起按退避重建，最长 5 / 10 分钟，都不影响打字。**只在用青简时同步**：切到别的输入法 30 秒后暂停，切回青简恢复。做这些事：

- **剪贴板**：本机复制的文本上传到素笺服务器；别的设备刚复制的（2 分钟内）直接写进本机剪贴板，`⌘V` 就能贴；更早的在子菜单里列出，点一条复制到本机。
- **学习数据与设置**：词频、选择、n-gram、敲错表、英文词、用户词，以及 `config.toml`（设置与自定义短语）在各台 Mac 之间合并。
- **输入日志**：输入法的 `input-log.jsonl` 上传到服务器；别的设备的下载到 `~/Library/Application Support/QingjianCloud/input-log/`。
- **大模型**：「大模型（云联想）」开着时，输入法的云联想（`[predict] provider = qingjian`）走素笺服务器的大模型代理，Mac 上不需要大模型密钥。

## 安装与登录

装 `cloud/scripts/publish-mac.sh` 发的输入法 pkg（或 `sujian` 分支的检出里 `apps/macos/scripts/bundle.sh --install`），同步模块就在里面。
从旧版（单独的 `QingjianCloud.app` 常驻程序）升级时，pkg 会把它和它的登录项删掉。

「中☁ → 青简 Cloud ›」里点「登录…」，会弹出素笺的登录页（用 Apple ID 或邮箱验证码），登录完自动回到输入法，菜单变成「已登录」。
四项功能缺省都关，在同一个子菜单里逐项打开：跨设备剪贴板、同步学习数据与设置、上传输入日志、大模型（云联想）。
切换时先告诉服务器，服务器那边关掉某项会同时删除这部分云端数据；在 iPhone 上关掉的，Mac 这边几秒内也跟着显示为关。
「退出登录」立即生效，同一账号再登录会接着用本机的同步进度。换了账号登录时，本机旧的同步进度（剪贴板游标、离线队列、学习数据基线）、
下载的别的设备的输入日志与本机的输入日志（`input-log.jsonl`）都会清掉，免得旧账号期间的输入传到新账号名下。

配置在 `~/Library/Application Support/QingjianCloud/config.toml`（仅本人可读），一般不用手改：

```toml
server = "https://pinyin.synon.ai"
token = ""          # 由「登录…」写入，不要手填
user_id = 0         # 登录的账号 id，由「登录…」写入
clipboard = false   # 以下四项在菜单里切换
sync = false
logs = false
llm = false
download_logs = true
```

旧版手填的 `qjc_` 设备令牌已经作废，升级后显示「未登录」，重新登录即可。这份配置不并进输入法的 `config.toml`：那份会同步到别的设备，令牌是每台设备自己的。
日志写在输入法的日志里（`~/Library/Logs/Qingjian/`）。

## 行为

- 带「密码」标记的复制（1Password、钥匙串访问等按 nspasteboard.org 约定标记的）不上传。
- **与苹果「通用剪贴板」共存**（两台 Mac 同一 Apple ID）：通用剪贴板从别的设备送来的内容（带 `com.apple.is-remote-clipboard`）不上传；
  收到别的设备的内容时，本机剪贴板已是同样的文字就不写；紧挨着的同一段文字 10 分钟内只传一次。三处一起防止两套同步互相回灌。
  不碰键盘鼠标，与「通用控制」无关。
- 离线时复制的内容进本地队列（落盘，重启不丢），恢复网络后按顺序补发；子菜单显示待上传条数，不弹通知。
- 「暂停同步」期间既不上传也不写入。
- 日志写在输入法的日志里：`~/Library/Logs/Qingjian/`。

## 学习数据与设置的验收（真机）

两台 Mac 都装好发布的输入法 pkg，用同一个账号登录并打开「同步学习数据与设置」：

1. A 上反复选某个非首选的词（比如打 `shiguo` 选第三个），「青简 Cloud ›」里「立即同步学习数据」，B 上也点一下，B 打同样的拼音时它已经排前面。
2. A 上造一个新词（云联想选中的、或自动造的），B 能直接打出来；B 上按删除修饰键删掉它，A 上也没了。
3. A 的偏好设置改双拼方案、加一条自定义短语，B 半分钟内生效。
4. 两台断网各自打字，恢复后都同步，词频是两边相加（看 `user.tsv`），不是二选一，也没有翻倍。
5. 子菜单显示「等输入法合并」时切到任意文本框打几个字，几秒后变成「刚刚同步」。

## 大模型与输入日志的验收（真机）

1. 服务器上配好大模型密钥；「青简 Cloud ›」里打开「大模型（云联想）」。
   青简「偏好设置 → 云服务」里地址变成 `https://<服务器>/v1`，点「测试连接」成功；打一段拼音停一下，候选末尾出现云端词。
2. 删掉 Mac 上原来的 DeepSeek 密钥（`.env` 里的 `QINGJIAN_API_KEY`）后，云联想照常工作。
3. 服务器上 `sujian-admin usage` 能看到这个账号的请求数与 token。
4. 打开「上传输入日志」，打几句话，半分钟后服务器上该用户的输入日志有这些上屏（`sujian-admin user list` 看会话数与最近活跃）；另一台 Mac 的
   `~/Library/Application Support/QingjianCloud/input-log/<设备名>.jsonl` 里也有。
5. 青简「偏好设置 → 高级 → 清空输入日志」后，服务器上该用户的输入日志为空，另一台下载的副本也被删掉。
6. 断网打字，打字不受影响；恢复后日志补传。

## 第 1 期验收（真机）

两台 Mac 都装好，用同一个账号登录并打开「跨设备剪贴板」，然后：

1. A 上复制一段中文，B 上 1 秒内能 `⌘V` 贴出来；反过来也一样。
2. 在 1Password（或钥匙串访问「拷贝密码」）里复制密码，另一台收不到，服务器日志里也没有。
3. A 关掉 Wi-Fi，复制两段，子菜单显示「离线 · 2 条待上传」；打字不受任何影响。打开 Wi-Fi 后 B 收到这两段。
4. A 合盖 5 分钟再打开，B 复制的内容 A 在 1 分钟内能收到。
5. B 上点子菜单里的历史条目，内容进 B 的剪贴板，A 不会收到重复的一条。
