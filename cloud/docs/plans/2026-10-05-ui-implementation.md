## 约束（已定，不再讨论）

1. **配色：键盘与 App 规则不同。** 键盘里，灰绿 accent 只给「代表某个人」的元素：牌子的人那半边、提示行、选中的对象格与头像、关于某人的提醒与事件、「记到 {某人}」，工作场景里一律换中性色（`ColorUsage.role(in:)`）。**App 里的配色照设计稿**：开关、引导的进度条与对勾、「同意并开始记录」、首页右上「+」、日历选中日等，设计稿画成灰绿就用灰绿（2026-10-05 审计会话定：设计稿是 App 的依据，「只给人」的规则只管键盘）；工作场景的人在 App 里仍用中性色。 App 字体用 MiSans（构建时下载，键盘仍用系统字体）。
2. **键盘不能打开 App，也不能用响应链绕过去**：「全部记忆」「去开启」只能在键盘里给文字提示路径（如「设置 → 通用 → 键盘 → 键盘 → 素笺 → 允许完全访问」「打开素笺 App → 通讯录」），不跳转。
3. **记忆功能要求开完全访问**；不开时素笺就是普通输入法（打字照常，牌子点开只有说明），满足审核指南 4.4.1。
4. **每个场景各自一组人，各自最多 8 个**；键盘里可以新建对象（建在当前场景，称呼先按 TA）。
5. **不要账号**：开通云服务就建空间，新设备用匹配码加入；找回与微信暂缓。界面里不出现「账号」「登录」「注册」（05 的 2j「删除账号」落地时改成删除空间一类的说法，待 1b 定文案）。
6. **本地续写暂缓**；「改写」只在开了云服务时显示（`IdleBar` 已按 cloud.toml 判断）。
7. **2A Task 9 与设计稿 01 的有意偏离**（截图审计时不按问题报）：
   1. 工具栏（候选栏）高 50pt（`KeyStyle.candidateBarHeight`），设计稿 `.k-bar` 46px；
   2. 首选候选带灰底（`KeyStyle.highlightFill`，与 iOS 自带键盘一致），设计稿只有字色；
   3. 1d 面板打开时保留提示行（`KeyboardView` 只在对象卡打开时让出提示行）；
   4. 1d 格子人多时换横排矮格子，最多三行、不滚动（`ScopeDisplay.cellStyle`，键盘扩展里 SwiftUI 滚动不可靠）；
   5. 1d 里点一个人就收起面板（设计稿要点「完成」）；
   6. 格子副文字超过两周写「n 周前」「n 个月前」（`ScopeDisplay.lastUsed`），设计稿只画到「上周」；
   7. 深色模式下牌子竖线用 `Theme.chipLine` 的深色值 #324235（设计稿没给深色，按明暗对调取）；
   8. 1d「新对象」在键盘里直接建（4fbf6c7，用户要求），设计稿写的是跳容器 App。
   9. App 底部标签栏在 iOS 26 上是系统的浮动玻璃样式，未选中项的 ink-3 不生效、不贴底、无上边线（设计稿 `.tabbar`）：「控件面原生」，不自绘（2026-10-05 审计会话定，T3）。
   10. 「我」页最底下加了不显眼的「重新看引导」（footnote 大小的 secondary 文字按钮，`MeView.replayOnboardingTitle`），设计稿 05 的 2j 没有这一项（T7）。
   11. 02 的 1c「到哪天」右侧写「提前 3 天提醒」（日子与约定都是），设计稿写「前一天提醒」：实际只有键盘提示行从 3 天前起提醒，照实写（2026-10-05 审计会话定，T6）。
   12. 05 的 2d（引导第 2 步）：完全访问那块标题改为「「允许完全访问」可以先不开」，正文与路径直接引用 `ScopeDisplay`；「这就能用了」去掉「自己写记忆卡、打字时提示」（要完全访问，原话误导）；加次按钮「先跳过」；「设置 → … → 素笺」是普通编号步骤加「添加好后回到这里」，不画对勾（App 测不到键盘加没加，不能假装已完成）（T7）。
   13. App 的衬线标题改用 MiSans（用户定，2026-10-05），字重照旧；键盘对象卡仍是 `SerifFont` 回退（按 PostScript 名取系统宋体 STSongti-SC，取不到回退 `.serif` 并记一次日志）。
   14. 02 的 1c「改一条」多一节「关键词」（最多 8 个）：设计稿没画，键盘提示行靠它命中，保留（T6）。
   15. 02 的 1d 对象设置多一行「所在场景」（只读，下有小字「换场景需要忘掉后重新加」）：每个场景各一组人、建好不能换场景（Task 9），设计稿没画（T6）。
   16. 02 的 1d 对象设置多一节「提示里怎么称呼」（她 / 他 / TA / 名字）：来自 05 的 2g 与 Task 9，提醒文案按它称呼，设计稿 1d 没画（T6）。
   17. 02 的 1b 对象详情多一节「待整理 · n 条」（`MaterialsSection`，素材计划 Task M2）：记一笔存下的原话，在卡片分组与「记一条」下面，新的在上；每条一行 11.5pt ink-3 小字「时间 · 剪贴板 / 手写」，下面 15pt 原话，收起时前 2 行，点开看全文（可选中复制）、右下「删除」（ink-2，也可左滑），删前系统确认框确认一次；没开素笺云时节末一行「开通素笺云后，每天帮你整理成记忆卡」（ink）进 `CloudIntroView`；未整理到 180 条时详情顶上一行 ink 提示「待整理快满了（n / 200）……」，同一个人只出一次。设计稿没画这一节：原话是素材不是卡，按约束 1 的 App 规则也没有可照的稿，一律中性色，不用灰绿（`ColorUsage.materialDelete` / `materialsCloudLink` / `materialsNudge`）。
