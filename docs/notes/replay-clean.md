# 干净回放口径（2026-10-07）

`qingjian-cli --replay <日志> --clean` 在原始口径之外再报一份「干净口径」：剔除日志里能机器判定为「当时选错了」的上屏再算命中率，
并按前后两半各报一次。规则与基线在这里冻结，**以后不改**；要改就另开一个口径、重报基线。实现在 `apps/cli/src/replay/clean/`。

## 为什么要它

回放把「当时上屏的文字」当标准答案。2026-10-04 的日志里有一批上屏是当时就选错了的：撤销改选的（rizhi 先上屏「日至」再撤销改「日志」）、
上屏后整个删掉重打的（shene → 神阿，删掉重打 shenme）、没打完的拼音尾巴混进了上屏（先IE、修改U）。
原始口径把它们也当答案，新库把「日至」改成「日志」反倒记一次退步；整句 165 条里旧库有 61 条不在候选，大半是这类。

## 规则（只用日志字段判定，不人工挑）

- **R1 撤销**：`retract` 的 `of` 指向此前最近一条同 `id` 的上屏（日志的 `id` 每个会话从头计），剔那一条。
- **R2 上屏后删掉重打**：`retype` 的 `of` 指向的上屏，作用域等于 `before` 且 `before ≠ after` 时剔它。
  组句内的重打 `of` 指这次上屏本身、作用域等于 `after`，不剔（core 的 `InputLogEntry::Retype` 文档）。
- **R3 汉字夹短字母**：上屏文字既有汉字又有字母、每段连续字母不超过两个，且整段**不能**由词库词拼成
  （C盘、U盘、T恤 这类中英混杂词已并进基础词库，拼得成就不剔）。

只在统计时剔，回放本身照常逐条走完，上文与内存学习和原始口径完全一样。前后两半按参与评测的条目（各来源合起来、按日志顺序）对半切，剔除在切半之后做。

## 干净口径 2（`--clean2`，2026-10-08，验收以它为准）

`--clean` 的剔除规则不变，另加**撤销回滚**：日志里每条撤销（retract）前，用户在真实使用里先把那次上屏及其后的字退格删掉了，
引擎靠 `note_backspace` 标记、下一次同拼音上屏时 `apply_retraction` 退回那次的学习（`engine/commit/mod.rs`；
单测 `engine/tests/learning.rs` 的 `erasing_the_last_commit_and_choosing_another_word_retracts_its_learning` 等）。
`--clean` 回放只计数不退格，被撤销的错选（rizhi 先上屏 日至、撤销改 日志）留着学习，之后同一段拼音还是它赢。
`--clean2` 遇到撤销时按回放里实际上屏过的字数逐字调同一个 `note_backspace`，回滚由引擎自己做，回放器里没有另一套逻辑
