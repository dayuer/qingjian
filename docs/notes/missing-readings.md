# 单字没有读音时会发生什么（2026-10-09）

`嗯` 在语料里出现 **288,255** 次、`诶` **35,620** 次，但两份产物里都查不到它们。追下来是一条链，不是某个环节的孤立 bug：

1. **Unihan 有 `嗯`，但读音是 `ń` / `ňg` / `ǹg`** —— 没有字母形式。建库时 `is_syllable` 把这些全过滤掉，
   字被判为「没有可用读音」而丢弃（`嗯` 就是这样；`诶` 的 `ēi` / `éi` 同理）。
2. 字没进词库 → **分词词表里也没有它** → `bigram` 统计语料时整段跳过 → **unigram 里没有** →
   最终词库照样没有。于是它永远缺席，而且**任何拿词级一元表当基准的检查都看不见它**（它从未被计数过）。

## 修了什么

- **单字读音用人工判定兜底**：`is_syllable` 之后一个可用音节都没有时，查
  `00_meta/pinyin-corrections.jsonl`（新增字符读音只在这里），`polyphone-apply.py` 也放行
  **词库读音为空**的单字（其余单字仍走字表那条路，不让单字标注冒充「已生效的修正」）。
  `嗯 = en`（依据：通行输入法都接受 en；《现代汉语词典》只给鼻音写法）。
- **两遍重建**：第一遍把字收进词库 → 拿它当**分词词表**重建二元（这一步才数得到）→ 第二遍带新频次建最终词库。

## 隔离实验：加字 vs 换分词词表（一次只改一个变量）

| | (a) 只加 `嗯`（底值 10）、LM 不动 | (b) 只换分词词表重建二元、无 `嗯` | 基线 |
|---|---|---|---|
| sentences / dialog / prose / external | **33.9 / 64.9 / 46.1 / 61.9**（逐位一致） | 32.0 / 64.9 / 44.3 / 60.0 | 33.9 / 64.9 / 46.1 / 61.9 |
| clean2 整句 | **71.0** | 70.3 | 71.0 |
| 同配置同音快照差异 | **13 行** | 49,142 行 | — |
| 5000 句留出集 修好 / 误伤 | **253 / 160 = +93** | 219 / 166 = +53 | — |

**结论**：(a) 零成本、有收益；**掉分全部来自 (b)** —— 与 `嗯` 无关。

## (b) 是单独的问题：分词词表与 lexicon 建出的词库不是同一份

`Vocabulary::segment` 是**用词频对数做词格 DP**（`score = best[start] + log_frequency[id]`），
所以分词结果取决于整份词表的**频次列**，不只是词条集合。产品底座（`base-cap100`）的二元用
`.lab/libs/base-single-w10/dict.tsv` 分词，而「两遍重建」那条链用 `lexicon` 当场建出的词库；
两份词表首两列差 20 处（东宁 / 东郡 / 休宁 / 位点 已按拆包规则移出基础库），频次列更是普遍不同
→ **整份语料的分词都变了** → 一元 / 二元统计随之改变 → 四把尺子掉 1.8~1.9。

**一个矛盾**：(b) 在自家留出集上反而**更好**（+1.06）却在四把尺子上**更差**（−1.9）。
「自家留出集」与「四把尺子」结论相反，取舍待定。
