# 词库体系规划（2026-10）

这一页定青简 / 素笺词库往后几年的形态：数据从哪来、怎么算分、怎么分包、怎么验收、怎么扩展。
对标资料见 [notes/lexicon-benchmark.md](../notes/lexicon-benchmark.md)，眼下的分层与清洗见 [plan/dictionary-layering.md](../plan/dictionary-layering.md)。

## 一、原则

1. **一把尺子。** 所有词条的分数都是同一个参照语料上的平滑对数概率（cost）。不再出现裸写的「次数」；没有语料证据的词，由脚本按「对着同音参照词定档位」换算，依据入库可追溯。
2. **数据即代码。** 每个数据源在清单里登记（地址、版本、哈希、许可、转换脚本），任何产物都能从清单一键重建，结果逐字节可复现。
3. **分层、分包、可开关。** 基础库瘦而准；领域、专名、网络、地区、时效内容都是独立包，有元数据、能单独升级和卸载。
4. **门槛先行。** 任何词库改动都要过自动门槛：整句评测、回放、同音快照、多音字审计、体积与内存预算、许可检查。不过门槛的改动合不进去。
5. **许可干净、隐私分离。** 随包数据只用与 GPL-3.0-or-later 兼容、能再分发的来源；用户的输入只进个人层，绝不回流基础库。

## 二、总体结构

```text
 数据源清单 sources.toml ──► 抓取 / 校验哈希 ──► 规范化 ──► 词条总表（lexeme store）
                                                          │
          参照语料快照（带日期）──► 统计 ──► 打分（cost）─┤
          读音三方校验 + 人工队列 ──────────────────────┤
                                                          ▼
                                   分层分包（manifest）──► .qj 包 + 元数据 + SHA256
                                                          │
                     门槛：评测 / 回放 / 同音快照 / 多音字 / 预算 / 许可
                                                          │
                                  发布：data-vN（随包） 与 包仓库（按需下载）
```

### 1. 数据源清单（`assets/lexicon/sources.toml`）

每个来源一节：`id`、`url`、`version`（或转储日期）、`sha256`、`license`（SPDX）、`redistributable`（能否随包）、`fetch`、`transform` 脚本、`attribution` 文案。
不能再分发的来源（例如许可未核实的语料）只允许产出统计量，不进包；构建脚本按 `redistributable` 拦截。

### 2. 词条总表（lexeme store）

一张规范化的总表，所有层都从它导出，不再各层各自维护 TSV。每个词条：

| 字段 | 说明 |
|---|---|
| `word` / `readings` | 词形；读音可多条，每条带 `reading_source`（人工 / Unihan / CC-CEDICT / 推断）与 `confidence` |
| `evidence` | 按语料快照分列的词次、文档频次（DF 只作收词依据，不进打分） |
| `cost` | 统一口径的分数，以及算出它的方式（语料 / 参照档位） |
| `tags` | `layer`、`domain`、`register`（书面 / 口语 / 网络）、`region`（大陆 / 台 / 港）、`era`（年份）、`sensitivity`（粗口等） |
| `status` | 收录 / 待审 / 拒收，附理由；拒收的也保留，防止反复加回 |

### 3. 打分

- `cost = -ln((c + α) / (N + αV))`：c 为参照语料混合里的词次，N 为总词次，V 为词表大小，α 由开发集定。
- 参照语料是**混合**的，按权重拼：百科（书面）、对话（口语）、现代网页 / 字幕（时效）。权重在开发集上调，写进清单。
- 没有语料证据的词：`cost = cost(参照词) + Δ(档位)`，档位只有几档（高于 / 略低于 / 远低于参照词）。参照词与档位都记在依据表里。
- 同音竞争的硬规则：新词不得把参照语料里明显更常用的同音词挤下首选（阈值在开发集上定，并由同音快照守住）。

### 4. 读音

- 三方校验：Unihan（kMandarin / kHanyuPinyin / kXHC1983）、CC-CEDICT、人工标注。两方以上一致才算可信。
- 大模型只能提**建议**，建议进人工队列，不直接写进总表。
- 「过了引擎不被丢」只证明字有这个音，不证明词里读对了；这一条写进审计口径。

### 5. 分层与分包

| 层 | 内容 | 形态 | 缺省 |
|---|---|---|---|
| L0 字 | 8105 规范字 | 基础库 | 开 |
| L1 核心词 | 常用词、高频语料词、短语层 | 基础库 | 开 |
| L2 当代口语 | 天天会打、同音不危险的网络 / 口语词 | 基础库 | 开 |
| L3 专名 | 品牌产品、人名姓氏、作品 | 独立包 | 品牌开，其余关 |
| L4 领域 | 医学、法律、IT、地名…… | 独立包 | 关 |
| L5 地区 | zh-TW、粤语 | 独立包 + 各自的语言模型 | 按地区 |
| L6 时效 | 网络用语、热词（带 `era`，可整批过期） | 独立包，可在线更新 | 关 |
| L7 个人 | 用户词、个人 n-gram、云端优化产物 | 本机 / 同步 | — |

每个包带一份 manifest：`id`、`version`、`layer`、`license` 与署名、条数、体积、`default_on`、`region`、`expires`（时效包）、所需引擎版本。

### 6. 语言模型

- 词库与语言模型由同一份词条总表和同一份参照语料导出，保证分数和搭配用的是同一把尺子。
- 短语、专名照旧走合成计数，不作新 token 重训。
- 演进：bigram → 剪枝后的 Kneser-Ney 三元模型（Mac 上先上，iOS 看内存预算）；字级神经重排只在内存允许的平台开（iOS 键盘 48–60MB 上限，目前不开）。

### 7. 发布与扩展

- **随包数据**：`data-vN`，文件名带日期版本，附 SHA256SUMS，由 `tools/release/data-bundle.sh` 发布。
- **包仓库**：可选包放在素笺云的包仓库，按需下载，用 ed25519 签名（沿用 `qingjian-update` 的验签）。时效包每周或每月更新，过期自动降权或卸载。
- **第三方包**：公开 `.qj` 包格式与 manifest 规范。用户和社区可以做自己的包；第三方包只能由用户主动导入，默认不进入同音快照门槛的对比基准。
- **热词**：只从公开语料（新闻、百科新条目、公开字幕）挖。若将来要用用户侧信号，只能是用户同意后的聚合统计，并设 k-匿名门槛，单个用户的输入永远不出现在任何包里。

## 三、质量门槛（CI）

| 门槛 | 内容 | 不过则 |
|---|---|---|
| 整句评测 | 新闻、口语、网络用语三套，首选 / 前三 / 字准 | 低于基线超过容差即失败 |
| 回放 | 冻结的输入日志回放 | 同上 |
| 同音快照 | 每组同音词前 5 名；常用词被挤下首选报警 | 未经确认的变化即失败 |
| 多音字审计 | 基础库多音字词条三方一致或有人工依据 | 新增无依据的即失败 |
| 预算 | 基础库体积、iOS 键盘常驻内存 | 超预算即失败 |
| 许可 | 每个随包产物在清单里有许可与署名 | 缺失即失败 |

每个词库 PR 都附一份差异报告：增删词、分数变化前 50、评测前后数字。

## 四、路线

| 阶段 | 内容 | 依赖 |
|---|---|---|
| 0（进行中） | 同音快照、多音字审计、评测基线、许可核实、source 列 | 无 |
| 1 | 数据源清单 + 词条总表；全部现有 TSV 迁入；统一 cost | 语料（下载中） |
| 2 | 参照语料加现代网页 / 字幕；新词发现（频次 + 凝固度 + 左右熵 + 人工审）；L2 定稿 | 阶段 1 |
| 3 | 包 manifest、包仓库与签名下载；L6 时效包在线更新 | 阶段 1 |
| 4 | L3 专名三包（品牌含混写、姓氏、作品） | 阶段 2 |
| 5 | L5 地区：zh-TW 词库 + 台湾语料语言模型 | 阶段 1 |
| 6 | 三元语言模型；按平台内存预算选择模型 | 阶段 2 |

## 五、红线

- 不引入雾凇、搜狗细胞词库等 GPL 不兼容或许可不清的数据。
- 不为凑数量把领域包默认全开，不做百万词大表。
- 不用大模型批量生成词条或词频直接入库。
- 不随包分发政治绰号与辱骂语。
- 用户输入、云端打字记录只进个人层。
